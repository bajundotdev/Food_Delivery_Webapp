# Assignment_2
Flask-based food delivery application for IFN582 group assignment

## Opening in VS Code Desktop

1. From the browser Codespace:
   - Click the menu (≡) in the bottom-left corner
   - Select "Open in VS Code Desktop"
   - Click "Open" when prompted

2. From VS Code directly:
   - Install the GitHub Codespaces extension
   - Press Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (macOS)
   - Type "Codespaces: Connect to Codespace"
   - Select your food delivery app Codespace
